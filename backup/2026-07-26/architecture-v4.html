企业连接

能力不保存生产地址和凭据。工具运行时统一处理权限、参数校验、超时和错误。

Skill 和 MCP 为什么不能合并
Skill 表达诊断方法。它决定什么时候调用工具、如何组合结果以及如何解释证据。
MCP 表达工具连接。它负责发现、鉴权、参数校验、执行和错误返回。同一个 Skill 可以调用多个工具，同一个工具也可以被多个 Skills 复用。
